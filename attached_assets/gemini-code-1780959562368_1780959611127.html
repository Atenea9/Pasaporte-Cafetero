Guía de Integración OCR Extendido: Cédula de Ciudadanía Digital

Este documento contiene todo el código fuente estructurado necesario para que Gemini 2.5 Flash realice un escaneo integral de la cédula colombiana (basado en la estructura de imagen.png) y auto-llene completamente el formulario en tu app de Replit.

Campos mapeados automáticamente: Cédula (NUIP), Nombres, Apellidos, Fecha de nacimiento, País, Región (Departamento) y Ciudad (Municipio).

1. Backend: Servicio de Extracción Estructurada (Node.js)

Actualiza la lógica de tu backend en Replit. El objeto de configuración fuerza a Gemini a responder en un JSON limpio mediante el responseSchema.

geminiService.js 
import { GoogleGenAI, Type } from '@google/genai';

const ai = new GoogleGenAI({ apiKey: process.env.GEMINI_API_KEY });

export async function extraerDatosCompletosCedula(base64Image) {
  try {
    const response = await ai.models.generateContent({
      model: 'gemini-2.5-flash',
      contents: [
        {
          inlineData: {
            mimeType: 'image/jpeg',
            data: base64Image
          }
        },
        'Analiza la cédula de Colombia y extrae de forma exacta: NUIP (como cedula), apellidos, nombres, convierte la fecha de nacimiento a formato YYYY-MM-DD, expande nacionalidad a nombre del país, y desglosa el lugar de nacimiento extrayendo el municipio como ciudad y el departamento dentro de los paréntesis como region.'
      ],
      config: {
        responseMimeType: 'application/json',
        responseSchema: {
          type: Type.OBJECT,
          properties: {
            cedula: { type: Type.STRING, description: 'Número de NUIP con o sin puntos' },
            nombres: { type: Type.STRING, description: 'Nombres de la persona en mayúsculas' },
            apellidos: { type: Type.STRING, description: 'Apellidos de la persona en mayúsculas' },
            fecha_nacimiento: { type: Type.STRING, description: 'Fecha de nacimiento mapeada a formato YYYY-MM-DD' },
            pais: { type: Type.STRING, description: 'País completo de la nacionalidad (ej: COL -> Colombia)' },
            region: { type: Type.STRING, description: 'Departamento del lugar de nacimiento (ej: CUNDINAMARCA)' },
            ciudad: { type: Type.STRING, description: 'Municipio del lugar de nacimiento (ej: BOGOTA D.C.)' }
          },
          required: ['cedula', 'nombres', 'apellidos', 'ciudad', 'region'],
        },
      },
    });

    return JSON.parse(response.text);
  } catch (error) {
    console.error("Error crítico en extracción OCR con Gemini:", error);
    return null;
  }
}

3. Frontend: Función de Auto-llenado Continuo

Actualiza la lógica de la función receptora handleScanned encargada de escuchar el evento del escáner OCR.

RegistroScreen.tsx (handleScanned) 
const handleScanned = (data: any) => {
  if (data) {
    setFormData(prevState => ({
      ...prevState,
      cedula: data.cedula || prevState.cedula,
      nombres: data.nombres || prevState.nombres,
      apellidos: data.apellidos || prevState.apellidos,
      fecha_nacimiento: data.fecha_nacimiento || prevState.fecha_nacimiento,
      pais: data.pais || prevState.pais,
      region: data.region || prevState.region,
      ciudad: data.ciudad || prevState.ciudad,
    }));
  }
};

5. Envío de Datos al Estado Global (AppContext.tsx)

Envía la información extendida a través de tu acción SET_USUARIO.

RegistroScreen.tsx (handleSubmit) 
const handleSubmit = async () => {
  const usuarioCompleto = {
    ...formData,
    nombres: formData.nombres ? formData.nombres.trim() : '',
    apellidos: formData.apellidos ? formData.apellidos.trim() : '',
  };

  dispatch({ type: 'SET_USUARIO', payload: usuarioCompleto });
  alert('¡Usuario registrado exitosamente!');
};
