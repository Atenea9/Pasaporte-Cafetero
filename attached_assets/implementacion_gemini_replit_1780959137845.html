Guía de Implementación: Campo fecha_nacimiento

Esta guía contiene el código completo y estructurado listo para copiar y pegar en tu entorno de Replit tanto para el Backend (Integración con la API de Gemini) como para el Frontend (RegistroScreen.tsx y visualización del Pasaporte Digital).

Requisito previo en Replit: Recuerda ir a la sección de Secrets (icono de candado) en Replit, añadir una variable llamada GEMINI_API_KEY y pegar allí tu clave generada en Google AI Studio. Asegúrate de instalar el SDK ejecutando npm install @google/genai en la consola.

1. Backend: Servicio de Extracción con Gemini (Node.js)

Crea o añade esto en tu archivo de servidor en Replit (por ejemplo, geminiService.js o dentro de tus funciones de API). Este código procesa la foto de la cédula en Base64, utiliza el modelo multimodal gemini-2.5-flash y fuerza una respuesta estructurada en formato JSON garantizando el formato YYYY-MM-DD.

import { GoogleGenAI, Type } from '@google/genai';

// Inicializa el SDK usando la variable de entorno configurada en Replit Secrets
const ai = new GoogleGenAI({ apiKey: process.env.GEMINI_API_KEY });

/**
 * Procesa la imagen de una cédula y extrae los datos clave usando Gemini OCR estructurado.
 * @param {string} base64Image - Cadena de la imagen en Base64 (sin el prefijo 'data:image/jpeg;base64,')
 */
export async function extraerDatosCedula(base64Image) {
  try {
    const response = await ai.models.generateContent({
      model: 'gemini-2.5-flash',
      contents: [
        {
          inlineData: {
            mimeType: 'image/jpeg',
            data: base64Image
          }
        },
        'Extrae de manera precisa el número de documento (cédula), nombres, apellidos y la fecha de nacimiento de esta identificación.'
      ],
      config: {
        // Obliga a Gemini a responder única y estrictamente en un JSON válido
        responseMimeType: 'application/json',
        responseSchema: {
          type: Type.OBJECT,
          properties: {
            cedula: { type: Type.STRING },
            nombres: { type: Type.STRING },
            apellidos: { type: Type.STRING },
            // Requerimiento de formato estandarizado
            fecha_nacimiento: { 
              type: Type.STRING, 
              description: 'Fecha de nacimiento extraída estrictamente en formato YYYY-MM-DD' 
            },
          },
          // Se deja fecha_nacimiento por fuera de required para que si la foto está borrosa o no se lee bien, la IA no falle y devuelva el resto de datos.
          required: ['cedula', 'nombres', 'apellidos'], 
        },
      },
    });

    return JSON.parse(response.text);
  } catch (error) {
    console.error("Error en la extracción con Gemini:", error);
    return null;
  }
}

2. Frontend: Modificaciones en RegistroScreen.tsx

A continuación se presentan los bloques de código que debes integrar o actualizar en tu archivo de pantalla de registro de React Native / TypeScript.

A. Definición del Estado del Formulario

Se añade fecha_nacimiento como una propiedad opcional (?) con string vacío por defecto, cumpliendo con el Requerimiento 3 para registros manuales.

// 1. Definición de la interfaz del estado del formulario
interface FormState {
  cedula: string;
  nombres: string;
  apellidos: string;
  fecha_nacimiento?: string; // Guardará el formato YYYY-MM-DD
}

// 2. Inicialización del estado en tu componente
const [formData, setFormData] = useState({
  cedula: '',
  nombres: '',
  apellidos: '',
  fecha_nacimiento: '', 
});

B. Mapeo en la Función de Escaneo (onDataExtracted)

Actualiza la función que recibe la respuesta del Backend/Gemini para mapear directamente la fecha (Requerimiento 1.3).

// Función encargada de actualizar los campos cuando la IA extrae los datos correctamente
const onDataExtracted = (extractedData: any) => {
  if (extractedData) {
    setFormData(prevState => ({
      ...prevState,
      cedula: extractedData.cedula || prevState.cedula,
      nombres: extractedData.nombres || prevState.nombres,
      apellidos: extractedData.apellidos || prevState.apellidos,
      // REQUERIMIENTO 1.3: Mapeo directo fecha_nacimiento -> fecha_nacimiento
      fecha_nacimiento: extractedData.fecha_nacimiento || prevState.fecha_nacimiento,
    }));
  }
};

C. Componente Input en la Interfaz de Usuario (UI)

Añade el elemento visual dentro del formulario de renderizado (Requerimiento 1.2). Al no añadir validaciones restrictivas de obligatoriedad, se mantiene opcional.

{/* REQUERIMIENTO 1.2: Input de fecha de nacimiento en la UI */}
<View style={styles.inputContainer}>
  <Text style={styles.label}>Fecha de nacimiento</Text>
  <input
    type="date"
    value={formData.fecha_nacimiento || ''}
    onChange={(e) => setFormData({ ...formData, fecha_nacimiento: e.target.value })}
    style={styles.webInput} 
  />
</View>
Nota de plataforma: El tag <input type="date" /> es idóneo si estás ejecutando tu proyecto en Replit apuntando a entorno Web (React Native para Web / Expo Web). Si estás compilando para dispositivos móviles nativos, sustituye este bloque por un componente de fecha como @react-native-community/datetimepicker.

D. Persistencia de Datos (Envío / Guardado)

Asegúrate de incluir el estado completo en el objeto final que se despacha hacia el almacenamiento local o base de datos (Requerimiento 1.4).

// REQUERIMIENTO 1.4: Guardar incluyendo la fecha de nacimiento en AsyncStorage o Firebase

3. Frontend: Visualización en el Pasaporte Digital

Para cumplir rigurosamente con el Requerimiento 2, la fecha debe guardarse como YYYY-MM-DD pero mostrarse de cara al usuario en formato legible DD/MM/YYYY.

A. Función Auxiliar de Formateo

Añade esta función en tu componente del Pasaporte o tarjeta digital:

/**
 * Transforma un string de fecha de YYYY-MM-DD a formato legible DD/MM/YYYY
 * @param {string} fechaInput 
 * @returns {string} fecha formateada o mensaje por defecto
 */
const formatearFecha = (fechaInput?: string): string => {
  if (!fechaInput) return 'No registrada';
  
  const partes = fechaInput.split('-'); // Divide la cadena [YYYY, MM, DD]
  if (partes.length !== 3) return fechaInput; // Retorno de seguridad por si ya viene formateada
  
  const [año, mes, día] = partes;
  return `${día}/${mes}/${año}`; // Retorna en formato DD/MM/YYYY
};

B. Renderizado del Pasaporte

Añade la etiqueta "Fecha de nacimiento" apuntando a la función transformadora dentro de la vista final:

{/* REQUERIMIENTO 2: Despliegue en el Pasaporte Digital */}
<View style={styles.passportCard}>
  <Text style={styles.passportTitle}>PASAPORTE DIGITAL DE VISITANTE</Text>
  
  <Text style={styles.infoText}><Text style={styles.bold}>Nombre:</Text> {visitor.nombres} {visitor.apellidos}</Text>
  <Text style={styles.infoText}><Text style={styles.bold}>Documento:</Text> {visitor.cedula}</Text>
  
  {/* Renderizado con etiqueta obligatoria y formato DD/MM/YYYY */}
  <Text style={styles.infoText}>
    <Text style={styles.bold}>Fecha de nacimiento:</Text> {formatearFecha(visitor.fecha_nacimiento)}
  </Text>
</View>
